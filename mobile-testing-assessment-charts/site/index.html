How it's counted

  • Code: a test method is one count. Commented-out tests are skipped. The source checkout and commit are shown at the top of the page.
  • iOS: func test… in firefox-ios-tests/Tests and BrowserKit/Tests. Smoketest = XCUITests annotated // Smoketest. Performance = PerformanceTests (XCUI) plus StoragePerfTests, kept out of the XCUI numbers so they are not counted twice.
  • Android: @Test in fenix/app/src/test (Robolectric when the class runs with AndroidJUnit4 or a Robolectric runner, JUnit otherwise) and src/androidTest (ui/ = E2E, split into Espresso/UIAutomator and the TAE framework's ui/efficiency/tests; the rest of ui/efficiency tests the TAE framework itself and is not counted as E2E; a Compose test rule elsewhere = component).
  • TestRail: Full Functional Tests Suite per platform. Automated = Completed, To automate = Suitable, Manual only = Unsuitable, Untriaged = anything else (Untriaged, Disabled, blank).
  • Scripts and workflow: testops-tools/mobile-testing-assessment-charts.
